# 小智狗 · 四舵机扩展方案（ESP32-C6 + 4×SG90）

> 状态：方案确认稿（待评审，未写固件代码）
> 日期：2026-10-16
> 目标硬件：xiaozhi-esp32-2.5.2（bread-compact-c6 板） + 4× SG90（180° 限位版）
> 参考：嘉立创 EDA-Robot（ESP8266 版，4 舵机 + Servo 库 + 网页/串口触发动作）

---

## 0. 一句话结论

可行，而且比表情狗更简单。4 个 SG90 固定在底板四角、机械臂当腿、左右镜像安装，做**站立 / 趴下 / 坐下 / 抬前腿 / 前进 / 后退 / 左转 / 右转 / 睡觉**这套动作。
动作逻辑直接复用嘉立创开源项目的角度序列（已修正限位余量），控制层接入小智的 **MCP 工具**，让 AI 自己决定何时动（对话兴奋时摇身、说"坐下"时坐下）。

**代价**：要改 `compact_c6_board.cc` 和 `config.h` 并重新编译烧录，**当前已验证可用的固件会被覆盖**。动手前必须先备份当前 bin。

## 1. 引脚分配（C6 安全脚）

嘉立创原项目用 ESP8266 的 14/16/12/13，**C6 不能用**。已逐一避开以下禁区：

- GPIO 24–30：内部 SPI flash 占用 ❌
- GPIO 16/17：UART0 串口日志 ❌
- GPIO 8：strapping（SPI boot）❌
- GPIO 0/1：0=strapping，1=已被 `LAMP_GPIO` 占用 ❌
- GPIO 4/5/6/7：音频 I2S ❌
- GPIO 9：BOOT 键 ❌
- GPIO 10/11：OLED I2C ❌
- GPIO 19/20/21：音量/触摸键 ❌
- GPIO 2：板载 LED ❌

**最终分配（4 路全部为干净空闲 GPIO，分散在不同端口组，无冲突）：**

| 腿 | 角色 | C6 GPIO | 备注 |
|---|---|---|---|
| 舵机1 | 右前 (RF) | **GPIO3** | 空闲 |
| 舵机2 | 右后 (RB) | **GPIO18** | 空闲 |
| 舵机3 | 左前 (LF) | **GPIO22** | 空闲 |
| 舵机4 | 左后 (LB) | **GPIO23** | 空闲 |

> 左右镜像安装：左侧舵机（3/4）与右侧舵机（1/2）摆臂朝向身体中轴线对称。
> 代码中用 `right_angle = 180 - left_angle` 处理镜像，嘉立创原代码正是这个约定。

## 2. 供电方案（已确认：外部 5V 独立供电）

- 舵机电源：**外部 5V / ≥3A 独立电源**（4× SG90 同时堵转最坏 ~2.6A，但站立/趴下是同步缓动，瞬时远小于此，3A 余量充足）
- ESP32 仍用原板供电（USB 或原电源），**不**从舵机电源取电
- **GND 必须共地**：舵机电源的 GND 与 ESP32 的 GND 用一根线连到一起，否则 PWM 脉冲无参考电平，舵机会乱抖
- 舵机电源入口并联 **1000µF 电解电容**（耐压 ≥10V），抑制上电/动作瞬间的电压跌落
- 信号线：ESP32 GPIO → 舵机信号脚，直接连，无需电平转换（C6 输出 3.3V 高电平，SG90 识别阈值 ~2.0V，OK）

接线草图：

```
          [外部5V/3A电源]──┬──[1000µF]──┐
                           │           │
                    舵机1~4的VCC   舵机1~4的GND
                           │           │
                           │      ┌────┴────┐
                           │      │ ESP32-C6│
                           │      │   GND   │←── 共地（关键）
                           │      └────┬────┘
                           │           │
                    舵机1~4信号 ───── GPIO3/18/22/23
```

## 3. PWM 控制参数

- 频率：**50 Hz**（周期 20 ms）
- 脉宽映射：**500 µs = 0° ，2500 µs = 180°**（与嘉立创 `servo.attach(pin,500,2500)` 一致）
- C6 实现方式：用 **LEDC**（4 timer / 6 channel，够用；C6 也支持 MCPWM，但 LEDC 更简单，且不与已有外设冲突）
- C6 的 LEDC 定时器为 20 位，在 50Hz 下分辨率约 0.5 µs，远超 SG90 所需的 5–10 µs，直接线性映射即可，无需查表微调
- 每个舵机对应 1 个 LEDC channel + 1 个 timer（或共享 timer，4 路各占 1 channel）

## 4. 姿态库（动作集）

直接复用嘉立创的角度序列，**修正两处限位风险**：

1. 嘉立创 `lie()` 用 `0°/180°` 极限角，SG90 会顶死机械限位 → 改为 `10°/170°` 留余量
2. 嘉立创 `dosleep()` 同样用 `0°/180°` → 改为 `10°/170°`
3. 增加显式 **`stand()`（站立/复位到 90° 中位）**，嘉立创把中位隐含在动作末尾，这里单独列出作为初始姿态

> 角度约定（与嘉立创一致）：**左侧腿(3/4) 从 0° 加，右侧腿(1/2) 从 180° 减；90° = 中位/站立基准**。
> 下面 `L` = 左侧角度，`R = 180 - L` 自动推出右侧。

### 4.1 基础姿态

| 动作 | 舵机1(RF) | 舵机2(RB) | 舵机3(LF) | 舵机4(LB) | 说明 |
|---|---|---|---|---|---|
| **stand 站立/复位** | 90 | 90 | 90 | 90 | 腿竖直撑地，所有动作的起点和终点 |
| **sitdown 坐下** | 140 | 90 | 40 | 90 | 仅前腿收起（嘉立创原版只动2/4，这里对称修正为动1/3前腿） |
| **lie 趴下** | 170 | 10 | 10 | 170 | 四腿收拢身体贴地（限位余量版） |
| **dosleep 睡觉** | 10 | 170 | 170 | 10 | 收成一团（限位余量版） |

### 4.2 步态动作（嘉立创原版角度，直接可用）

- **front 前进**：对角步态，2/3 先迈 → 1/4 后蹬 → 交换，每步 `delay(100)`
- **back 后退**：front 反向
- **left 左转**：循环 3 次，身体左偏摆
- **right 右转**：循环 3 次，身体右偏摆
- **toplefthand 举左手**：舵机3 在 0°↔30° 间循环 3 次（左前腿抬）
- **toprighthand 举右手**：舵机1 在 180°↔150° 间循环 3 次（右前腿抬）

> 完整角度序列见嘉立创文档 `4.6.8 运动控制` 章节（已提取，与本方案第 4 节一致）。

### 4.3 AI 表现动作（小智特有，接 MCP）

这些是小智对话时的"情绪外显"，由 AI 通过 MCP 工具触发：

| 动作 | 触发语义 | 实现 |
|---|---|---|
| **wag 摇身** | 兴奋/开心时 | 身体左右小幅摆动（在 stand 基础上 ±15° 交替） |
| **bow 鞠躬** | 打招呼/致谢 | 前腿前伸（舵机1/3 前推），后腿撑住 |
| **alert 警觉** | 被唤醒/听指令 | 前腿微抬 + 短停 |

## 5. 安全设计（必须做，照搬开源项目踩坑经验）

1. **上电先回中位**：初始化时四路先 `write(90)`，延时 **≥300ms** 后再使能 LEDC 输出，防止四个舵机同时猛冲到限位堵转发热
2. **软件硬夹限位**：每个舵机定义 `min=10° / max=170°`，所有角度写入前 `clamp()`，杜绝越界烧齿轮
3. **动作间插值过渡**：嘉立创原版是"写角度 + delay"的硬跳。我们改为**小步长插值**（每步 5°，步间 20ms），既保护 SG90 齿轮，也更像真狗。这是相对嘉立创的主要改进点
4. **MCP 只暴露语义动作**：AI 只能调用 `stand/sitdown/lie/wag/bow/alert/front/back/left/right` 这类**命名动作**，绝不能让 AI 传裸角度——传角度 = 让语言模型直接控制机械限位，会烧硬件
5. **外部电源监测（可选）**：若日后改电池供电，加 ADC 欠压保护；当前外部 5V 方案可省略，但 **1000µF 退耦电容必加**

## 6. 软件接入架构

```
小智对话 → LLM 决策 → 调用 MCP 工具 "actuator_move"
                              │
                              ▼
                   actuators_mcp_tool（新增）
             暴露语义动作名 + 可选幅度/次数
                              │
                              ▼
                   DogLegController（新增类）
              - 4× LEDC channel 初始化
              - setAngle(servo, deg) 带 clamp + 插值
              - playAction(name) 查姿态库执行
                              │
                              ▼
                   compact_c6_board.cc 注册到 Board
              config.h 增加 SERVO_*_GPIO 宏
```

- **新增文件**：`main/actuators/dog_leg_controller.h/.cc`、`main/actuators/actuators_mcp.cc`（MCP 工具注册）
- **修改文件**：`compact_c6_board.cc`（构造时初始化 DogLegController，提供 `GetActuator()` 接口）、`config.h`（加 4 个 GPIO 宏）
- **MCP 工具**：在现有 `mcp_server.cc` 注册一个新 tool `actuator_move`，schema 为 `{action: enum, repeat: int, amplitude: int}`
- **与表情联动（可选增强）**：在 `SetEmotion` 触发开心时，自动回调 `playAction("wag")`，实现"屏上笑 + 尾巴摇"的呼应

## 7. 分阶段验证步骤（降低风险）

**阶段 0 — 备份**
- 用 `esptool.py read_flash` 备份当前已验证固件 bin（保留回退能力）

**阶段 1 — 只点灯不烧机（纯逻辑验证）**
- 先只改 `config.h` 加宏 + 写 `DogLegController` 骨架，MCP 工具返回"would move X to Y°"但不真输出 PWM
- 编译烧录，用 MCP 调用确认动作名/角度计算正确，**不接舵机**

**阶段 2 — 单舵机验证**
- 只接 1 个舵机 + 外部电源共地，跑 `stand`/`sitdown`，确认角度、限位夹、插值正常，舵机不抖不烫

**阶段 3 — 四舵机静态姿态**
- 接齐 4 个舵机，依次验证 stand/lie/sitdown/dosleep 四个静态姿态，确认机械安装方向正确（镜像对称）

**阶段 4 — 步态 + AI 联动**
- 验证 front/back/left/right 步态；接入 MCP，让小智对话触发 wag/bow
- 最后做"屏笑 + 摇身"联动

## 附：嘉立创原动作代码（参考，C6 端改写为 LEDC + 插值版）

```cpp
// 嘉立创 ESP8266 原版（仅参考，不直接用于 C6）
servo1.attach(14, 500, 2500);  // RF
servo2.attach(16, 500, 2500);  // RB
servo3.attach(12, 500, 2500);  // LF
servo4.attach(13, 500, 2500);  // LB
// 全部 write(90) 复位

void front() { /* 对角步态，2/3先迈→1/4后蹬→交换，每步delay(100) */ }
void back()  { /* front 反向 */ }
void left()  { /* 循环3次左偏摆 */ }
void right() { /* 循环3次右偏摆 */ }
void sitdown() { servo2.write(140); servo4.write(40); delay(3000); 复位; }
void lie()     { servo1.write(180); servo3.write(0); servo2.write(0); servo4.write(180); delay(3000); 复位; }
void dosleep() { servo1.write(0); servo3.write(180); servo2.write(180); servo4.write(0); }
void toplefthand()  { servo3 在 0↔30 循环3次; }
void toprighthand() { servo1 在 180↔150 循环3次; }
```
